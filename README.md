# My Life

A small personal website where you can explore parts of my life through an interactive world map.

Click on locations to open stories about places that are important to me, or click the plane to contact me.

## How It Works

The website starts with a world map.

Click a location pin:

```text
MAP  ←  STORY
```

The map slides away and the story for that location appears.

Click **Back** to return to the map.

Click the airplane:

```text
CONTACT
   ↑
   ↑
  MAP
```

The contact page slides up from the bottom.

## Run It Locally

Clone the repository:

```bash
git clone https://github.com/WinnyT/winny_web
```

Open the project folder and open:

```text
index.html
```

in your browser.

You can also use a local development extension such as Live Server in VS Code.
